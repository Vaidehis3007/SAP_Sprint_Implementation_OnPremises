# SAP Sprint Implementation (On-Premises)

## Overview

This repository contains the implementation of a comprehensive SAP ABAP development sprint focused on building and integrating enterprise application components using both classical and modern SAP technologies. The project simulates real-world SAP development scenarios involving data modeling, report generation, document creation, service development, and SAP Fiori-based application development. The primary business use case implemented is **Purchasing Info Records by Vendor**, where vendor and material-related purchasing information is managed, processed, and exposed through multiple SAP technologies.

---

## Technologies & Concepts Covered

### Classical ABAP Development

* ABAP Data Dictionary
* Custom Tables & Table Maintenance Generator (TMG)
* Internal Tables and Data Processing
* Object-Oriented ABAP
* Object-Oriented ALV Reports
* Selection Screens

### Forms & Document Generation

* Adobe Forms
* Dynamic Data Binding
* Business Document Generation

### Integration & Services

* OData Services (CRUD Operations)
* SAP Gateway (SEGW)
* BAPI Integration
* Proxy-Based Communication

### SAP S/4HANA Development

* CDS Views
* Data Modeling
* Calculated Fields
* View Extensions

### RAP (RESTful ABAP Programming Model)

* Read-Only Applications
* Managed CRUD Applications
* Unmanaged CRUD Applications
* Service Definitions & Bindings
* SAP Fiori Elements Integration

### Additional Implementations

* Material Creation using BAPI
* Email Sending Functionality
* RAP Singleton Pattern
* RAP Proxy Consumption
